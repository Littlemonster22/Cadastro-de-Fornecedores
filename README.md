O código faz parte do projeto 2 da matéria de Programação II, consistindo em uma aplicação única para a turma, um Sistema Empresarial de Vendas, onde cada grupo desenvolveu um módulo (Meu grupo desenvolveu a parte de Gestão de Fornecedores);

Esse projeto teve o intuito de colocar em prática os assuntos vistos na disciplina, principalmente os da segunda unidade (ponteiros, alocação dinâmica de memória, bibliotecas e recursividade);

Para executar o código, basta baixar o arquivo fornecedores.exe, ou se quiser ver o código-fonte por completo, baixe todos os arquivos necessários para a compilação (fornecedores.cpp, fornecedores.h e gconio.h).
