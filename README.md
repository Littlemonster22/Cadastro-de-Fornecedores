O código faz parte do projeto 2 da matéria de Programação II, consistindo em uma aplicação única para a turma, um Sistema Empresarial de Vendas, onde cada grupo desenvolveu um módulo.
Esse projeto teve o intuito de colocar em prática os assuntos vistos na disciplina, principalmente os da segunda unidade (ponteiros, alocação dinâmica de memória, bibliotecas e recursividade).
